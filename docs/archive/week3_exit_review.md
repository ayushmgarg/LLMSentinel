## The demo

- **Framework:** Streamlit, one file (`src/llmsentinel/demo/app.py`), no build
  step, no JS, no credentials. Launch: `python scripts/run_demo.py` (or
  `streamlit run src/llmsentinel/demo/app.py`), served at `http://localhost:8601`.
- **Structure:** the page is a pure view. All analysis is in
  `llmsentinel.demo.pipeline`; all decisions in `llmsentinel.policy`. The
  headless runner `scripts/demo_run.py` exercises the identical scenarios, so
  the recorded fallback and the live page cannot diverge.
- **Data:** `data/demo/rag_corpus.yaml` (a fictional notes-app KB + one poisoned
  page) and `data/demo/mcp_fixtures.yaml` (clean/poisoned tool responses, and
  benign/poisoned/changed-hash manifests). All CC0, reserved-`.invalid`
  destinations, placeholder secrets.

## Manifest drift

The `changed_hash` manifest is the benign tool silently rewritten after approval.
Its new description reads harmless, yet the demo reports **manifest drift**
against the pinned digest — a silent change to an approved tool is itself the
signal, independent of the new content's risk score.

## Response time

Per-scenario analysis is ~200–250 ms wall clock (rules-only, shown on the page
as "analysed in N ms"; 223 ms for the poisoned RAG case). No GPU, no model
load: the demo starts instantly from a clean checkout.

## Determinism and safety

- Retrieval is TF-IDF cosine over a fixed local corpus — same result every run.
- The policy is a table lookup; the same (action class, risk band) always yields
  the same outcome. `tests/test_demo.py` and `tests/test_policy.py` assert it.
- Nothing executes. `DemoResult.policy_decision` is data; the AST test in
  `test_policy.py` proves the policy package imports nothing that could act.

## Limits (shown in the demo's own disclaimer panel)

Research prototype; defence in depth, not a guarantee. The detector shown in the
demo is rules-only for zero-dependency startup — the transformer and hybrid are
the systems evaluated in `docs/EXPERIMENTS.md`. Risk bands come from rules-only
dev thresholds; if `results_dev.json` is absent everything bands LOW and the
page says so.

## Reproduce

```bash
python scripts/demo_run.py          # headless, deterministic, the recorded fallback
python scripts/run_demo.py          # the live Streamlit page at localhost:8601
python -m pytest tests/test_demo.py tests/test_policy.py -q
```
